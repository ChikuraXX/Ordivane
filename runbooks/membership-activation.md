# 会员异常处理手册 v1

1. 查询订单状态、权益及处理记录，确认都是当前订单与权益类型。
2. 权益已开通：只验证，不重复开通；业务响应超时不代表失败。
3. 订单已退款/关闭：禁止重放，转人工记录原因。
4. 依赖暂不可用：等待复查，不能把无法查询当成权益不存在。
5. Schema 不支持：阻止执行，修复适配后建立新计划。
6. 已支付、未退款、权益确认不存在、无冲突执行且 Schema 合法：可提出原始重放计划，经他人审批和执行前复检后处理。
7. 投递成功不等于业务成功；查询权益和处理记录。验证到期仍不确定则保留 UNKNOWN，转人工查证。

该手册辅助调查；业务服务在事务中执行权威约束，文本不能覆盖代码规则。
